## 📖 Overview

**P2.design** is a clean, modern landing page concept designed to showcase the legendary **Porsche 911 GT3**. 

Built purely with vanilla **HTML5 and CSS3**, this project highlights responsive flexbox layout composition, automotive visual branding, bold typography, and technical performance metrics without any heavy JavaScript frameworks or CSS libraries.

---

## ✨ Key Features

- 🎨 **100% Handcrafted Code**: Clean, semantic HTML structure and modular CSS styling written from scratch.
- 🧭 **Header Navigation**:
  - Sleek brand emblem logo
  - Navigation links (*Highlights*, *Performance*, *Design*, *Charging*, *Configure*)
  - High-visibility *"TEST DRIVE"* call-to-action button
- 🏎️ **Hero Showcase Section**:
  - Prominent **911 GT3** statement typography
  - High-resolution hero car visual display
- 📊 **Performance Specs & Footer**:
  - Performance highlights counter: **412 km WLTP**, **0-100 km/h in 2.8s**, **560 HP**
  - High-octane racetrack photo gallery showcasing track performance and aerodynamics
- ⚡ **Zero Dependencies**: Pure web standards, blazing-fast load times, and no build setup required.

## 🚀 Getting Started

You can preview and run this project locally without any tools or dependencies:

### 1. Clone the repository
```bash
git clone https://github.com/sachin07-a/P2.design.git
```

### 2. Navigate to the project directory
```bash
cd P2.design
```

### 3. Open in Browser
- Double-click `index.html` or `p2.html` to open it directly in your browser (Chrome, Brave, Edge, Firefox), or
- In **VS Code**, right-click `index.html` and select **"Open with Live Server"**.
